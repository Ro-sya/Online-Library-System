# Online-Library-System

Репозиторій містить ER-модель та специфікацію для системи "Онлайн-бібліотека".

## Структура проєкту 
- `spec.md` - основна специфікація вимог та ER-моделі (Mermaid).
- `DEFENSE.md` - матеріал для захисту роботи.
- `prompt/` - інструкція та промти, використані для генерації ші-схеми.

## Домен
Система зберігає дані про: 
- читачів (`Reader`), 
- книги (`Book`), 
- авторів (`Author`),
- жанри (`Genre`),
- доступ до книг (`Digital Access`).
